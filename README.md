# 🩸 LifeLink – Smart Blood Bank Management System

**Connecting Donors. Empowering Hospitals. Saving Lives.**

**An OS-DBMS Integrated Project | Python Flask | MySQL**

LifeLink is a smart blood bank management system designed to simplify blood donation management, inventory tracking, emergency blood requests and donor coordination.

The platform connects blood donors, hospitals and blood banks through a centralized web application, incorporating intelligent donor matching, emergency request prioritization, blood inventory management and automated notifications.

LifeLink integrates practical concepts from **Operating Systems (OS)** and **Database Management Systems (DBMS)**, including process management, multithreading, CPU scheduling, synchronization, deadlock handling, database transactions, concurrency control and file management.

## 🚀 Project Vision

To create a reliable and efficient digital platform that improves blood donation coordination, simplifies emergency blood requests and supports better blood inventory management.

**Every drop matters. Every connection saves a life.**
